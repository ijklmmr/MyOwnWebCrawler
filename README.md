## 📖 About

This repository contains a mini-project developed using **Go (Golang)**.


### Prerequisites

Make sure you have Go installed.

[Download Go](https://go.dev/dl/)

### Installation

Clone the repository:

```bash
git clone https://github.com/ijklmmr/MyOwnWebCrawler.git
```

Navigate to the project directory:

```bash
cd MyOwnWebCrawler
```

Run the project:

```bash
go run .
```
